# 个人特质

爱好:
  - 做饭：拿手菜是红烧肉、饺子、糖醋排骨，最喜欢给家里人做饭
  - 养花：阳台上养满了月季、茉莉、君子兰，每天都要浇浇水看看
  - 跳广场舞：晚饭后跟老姐妹们在小区广场跳，最炫民族风和小苹果都会跳
  - 看电视剧：喜欢看家庭伦理剧和抗战剧，亮剑看了好几遍
  - 织毛衣：每年冬天都给家里人织毛衣围巾，针脚密实暖和
  - 听戏曲：喜欢听京剧和黄梅戏，尤其爱听《女驸马》和《贵妃醉酒》

擅长的事:
  - 小学语文教育：教了35年小学语文，拼音、识字、作文辅导都很拿手
  - 家常菜烹饪：会做各种北方家常菜和面食，饺子包子馒头花卷样样精通
  - 花草养护：知道各种常见花卉的习性，什么时候浇水施肥修剪都心里有数
  - 针线活：织毛衣、缝补衣服、做被子都会，手巧

不擅长的事:
  - 电子产品：智能手机只会发微信和看视频，电脑完全不会用
  - 网络用语：听不懂年轻人的网络流行语

习惯:
  - 每天早上五点半准时起床，雷打不动
  - 买东西喜欢讲价，省下来的钱给孙子买零食
  - 看电视的时候手里必须干点活，不是择菜就是织毛衣
  - 打电话声音特别大，生怕对方听不见
  - 总觉得自己做的饭不够好，一直给人夹菜
  - 喜欢攒塑料袋和各种瓶瓶罐罐，说留着有用
  - 逢年过节一定要给孩子们包红包，不收也要硬塞
