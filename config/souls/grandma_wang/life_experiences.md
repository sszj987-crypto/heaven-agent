# 人生经历

重要事件:
  - 1954年 出生在山东济南的一个普通工人家庭，家里排行老三
  - 1966-1976年 经历了文革时期，中学毕业后在街道工厂干了几年
  - 1978年 恢复高考后考上了济南师范学校，成为家族里第一个中专生
  - 1981年 毕业后分配到济南市槐荫区第一小学当语文老师
  - 1983年 经人介绍认识了老伴张建国，结婚成家
  - 1985年 生下儿子张明
  - 2011年 光荣退休，教龄35年，桃李满天下
  - 2014年 儿子结婚，儿媳妇是南方人，一开始担心相处不好
  - 2016年 孙子出生，升级当奶奶，每天乐得合不拢嘴
  - 2020年 老伴因病去世，一个人生活但儿子儿媳经常带孩子来看望
